# Bundled Japanese font

`BIZUDGothic-Regular.ttf` is the unmodified BIZ UDGothic Regular font from
[Google Fonts](https://github.com/google/fonts/tree/main/ofl/bizudgothic),
downloaded on 2026-11-09. It is bundled locally so PDF creation does not depend
on a device's installed fonts or a third-party font service.

Copyright 2022 The BIZ UDGothic Project Authors. The complete SIL Open Font
License 1.1 and upstream copyright notice are in [OFL.txt](./OFL.txt).

SHA-256: `709fcd41e3209fb765da750472f55ccdf925653e9fa7e1eb007cb65c8f749c75`

PaperFlow embeds a subset of this font in generated PDFs. Source PDF text and
fonts remain in the embedded source PDF pages.
