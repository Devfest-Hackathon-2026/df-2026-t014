# 詳細テスト仕様書

成果物: [PaperFlow 詳細テスト仕様書](../outputs/paperflow-20261110/PaperFlow_詳細テスト仕様書.xlsx)

設計v3と当初の88項目を基準に、全415件を作成した。機能・境界228件、Google・復旧104件、実機・性能50件、名簿取込・設定33件。正常系、異常系、境界値、マージナル、回帰を区別し、各ケースに前提、具体的なデータ、手順、期待結果、保つ条件、後片付けを記載する。

全415項目の結果欄を更新した。合格367件・保留48件・不合格0件。結果欄は実際の結果、環境、証跡、残る条件を記載し、修正前後の履歴は証跡を参照できる。物理装置・学校アカウント・教師が必要な項目には保留理由を記録した。

Excel の証跡欄にある `artifacts/` のパスは検証時の作業環境を指す。このリポジトリには Excel の結果と、再実行に必要な架空データの fixture を収録する。

自動テストは `npm ci` に続けて `npm test -- --maxWorkers=2` で実行する。`tests/fixtures/` には、合成した暗号化 PDF と、架空名簿を使った QR 照合の出力を置く。自動テストの件数と Excel の 415 ケースの判定は別に集計する。

マージナルには、容量/件数/文字数/失効時間の直前・一致・直後、並び順、部分失敗、同時操作、斜行・低dpi・小さいQR・裏写りなどの複合条件を含む。99%・60秒・90秒は設計の暫定目標。実測値と測定環境を併記し、合成PDFの値を実紙の達成値へ読み替えない。

PC Chromeを基本に、学校アカウント・実プリンター・複合機が必要な項目を識別した。API/時計stub、原稿・破損PDF・QR画素・大容量PDF・名簿のfixtureを実行時に作成した。実機スキャンの原本や協力者を必要とする条件は、合成fixtureで代替完了にしない。

Excelの構成はテスト管理、機能・境界、Google・復旧、実機・性能、名簿取込・設定、要件対応、準備・判定、本人の作業。フィルター、見出し/ID固定、結果の選択欄、集計を付けている。
